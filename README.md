# Project details

NearFind is a mobile platform designed to connect consumers with nearby local shops. It helps users quickly find specific products available in their area through product-level search, AI-driven recommendations, store directions, time-limited promotions, and pre-order/reservation options.

## Project dependencies

All dependencies can be installed via npm install

- React native packages. Can be installed via:

  ```
  npm install expo
  ```

- [React native keyboard aware scroll view](https://github.com/APSL/react-native-keyboard-aware-scroll-view), an external react native package that provides an external component. Install via:
  ```
  npm i react-native-keyboard-aware-scroll-view --save
  ```

## Running the project

To run the project and emulate it in a device run the following in your terminal:

```
npx expo start
```

Then scan the generated QR code using Expo Go in your mobile device
